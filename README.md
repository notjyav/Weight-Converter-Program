# Weight Converter

A simple command-line Java program that converts weight between pounds (lbs) and kilograms (kgs).

## Features

- Convert lbs to kgs
- Convert kgs to lbs
- Handles invalid menu choices

## Requirements

- Java JDK 11 or newer
- IntelliJ IDEA (optional)

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.
4. Choose an option, enter the weight, and press Enter.

## Example

```
Weight Converter Program
1: Convert lbs to kgs
2: Convert kgs to lbs
Choose an option: 1
Enter the lbs amount to convert: 150
The new weight in kgs is 68.04
```

## Concepts Used

- `Scanner` for user input
- `if` / `else if` / `else` statements
- `printf` for formatted output
